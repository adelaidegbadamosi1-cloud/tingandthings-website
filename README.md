## Upload to GitHub

1. Download and unzip the package.
2. In your GitHub repository, choose **Add file → Upload files**.
3. Drag all files into the upload area.
4. Select **Commit directly to the main branch** and commit.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch `main` and folder `/ (root)`, then Save.
8. Wait a few minutes for the published URL.
